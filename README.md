# Big Mart Sales Prediction

## Overview

This project predicts product sales for Big Mart outlets using machine learning techniques. The objective is to forecast sales based on product characteristics, outlet information, and historical sales data.

## Features

* Data preprocessing and cleaning
* Missing value imputation
* Label Encoding of categorical features
* Exploratory Data Analysis (EDA)
* Sales forecasting using XGBoost Regressor

## Dataset

Big Mart Sales Dataset containing:

* Product attributes
* Outlet characteristics
* Historical sales information

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* XGBoost

## Machine Learning Pipeline

1. Data Loading
2. Missing Value Treatment
3. Feature Engineering
4. Label Encoding
5. Train-Test Split
6. XGBoost Model Training
7. Sales Prediction
8. Performance Evaluation

## Results

* Training R² Score: 0.88
* Test R² Score: 0.53

## Key Learnings

* Handling missing values
* Feature engineering for structured datasets
* Regression modeling
* Model evaluation using R² metrics
